# Winter Language

Английский, польский и немецкий по методу 20 часов: карточки с интервальным повторением,
тесты, озвучка слов, диалоги из жизни, дневная цель и серия дней. Около 430 самых нужных слов,
разложенных по темам от самых полезных. Интерфейс: русский, украинский, английский, польский.

Раньше это была вкладка «Учёба» в **КБЖУ Трекере**. Прогресс переносится:
в КБЖУ открой «Учёба» → «Сохранить прогресс», затем в Winter Language — Настройки →
«Выбрать файл из КБЖУ» (подходит и обычная резервная копия КБЖУ). Уже выученное здесь не теряется.

## Установка

Приложение семейства **Winter Hub** (Android + Windows). Удобнее всего ставить и обновлять через
Winter Hub, либо скачать из **Releases**: `Winter-Language.apk` для телефона, `Winter-Language-Setup.exe` для ПК.

## Как устроено

Flutter (Dart).
- `lib/learn/` — словарь, диалоги, интервальное повторение (система Лейтнера), озвучка
- `lib/life/life_store.dart` — прогресс (формат совпадает с КБЖУ, поэтому перенос без потерь)
- `lib/screens/` — экраны учёбы, тестов, диалогов и настроек
- `tools/android/MainActivity.kt` — озвучка через синтезатор речи Android (на ПК — голоса Windows)

Сборку делает GitHub Actions при каждом изменении в `main`: анализ кода, тесты (`test/`), APK и
установщик для Windows, подпись постоянным ключом (общие скрипты в `winter-hub/ci`), публикация в Releases.
